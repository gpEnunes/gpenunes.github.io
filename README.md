# Emerson Nunes

Static portfolio for [gpenunes.github.io](https://gpenunes.github.io). Next.js App Router, exported to `out/` and published with GitHub Pages.

Deploy is GitHub Pages only, from `.github/workflows/pages.yml` on pushes to `main`.

```bash
npm install
npm run build
```

English is at `/`, `/writing`, and `/writing/[slug]`. Portuguese is under `/pt`. Projects and the about text are on the homepage. Essays are markdown in `content/blog`. Project cards are markdown in `content/projects`.
